# TANKUS

Яркая 3D party arena game на 2–8 игроков на **Godot 4.7.x** с карточной прогрессией способностей между раундами в стиле *ROUNDS*.

---

## 🎮 Управление

| Действие | Клавиша / Ввод |
| :--- | :--- |
| **Движение** | `W`, `A`, `S`, `D` (относительно ориентации камеры) |
| **Прыжок** | `Space` |
| **Прицеливание и обзор** | Мышь (вращение камеры от 3-го лица, прицел в центре) |
| **Стрельба** | Левая кнопка мыши (`LMB`) |
| **Ручная перезарядка** | `R` |
| **Защитный блок (щит)** | `E` |
| **Таблица счёта / Билды** | `Tab` (удержание в матче) |
| **Пауза / Освободить мышь** | `Esc` |
| **Режим отладки (Debug)** | `F3` (цифровые статы, каталог карт, тест-драйв по `Tab`, см. [docs/debug_mode.md](docs/debug_mode.md)) |

## 🎯 Боевые механики

* **Снаряды и баллистика:**
  * **Вооружение танка:** темп огня 0.55 с, базовый магазин на **6 снарядов**, перезарядка 1.8 с (автоматическая при 0 снарядов или ручная по клавише `R`).
  * **Базовый снаряд:** взрывается и наносит урон при столкновении с препятствием или танком (28 ед. урона, 24 м/с). **По умолчанию рикошета нет (0 отскоков)**.
  * **Рикошет (Ricochet System):** активируется исключительно карточной прогрессией способностей (например, карта `Bouncy` добавляет +1 рикошет от стен, а карта `Ricochet Power` увеличивает урон и скорость снаряда после каждого отскока).
* **Защитный блок (Shield):** кратковременный щит на клавишу `E` (0.35 с), поглощающий вражеские снаряды и перезаряжающийся 3.0 с.

## 🏗️ Структура проекта

```text
res://
├── autoload/          # Глобальные синглтоны (Game, Network, MusicManager)
├── core/              # Данные матча (MatchRules, PlayerInfo, TeamInfo)
├── tank/              # Сцена танка, компоненты (контроллер, ввод, оружие, блок, статы)
├── projectile/        # Сцена физического снаряда с рикошетом
├── abilities/         # Ресурсы способностей (CardDefinition), база карт, эффекты
├── maps/              # Карты арены (Sky Courtyard, Iceworks, Pendulum Yard, Shift)
├── match/             # Контроллеры матча, раундов и спавн-менеджер
├── network/           # UDP Discovery для LAN, сетевой ввод
├── ui/                # HUD, меню лобби, экран драфта карт, таблица счёта
├── vfx/               # Визуальные эффекты (взрывы, вспышки, следы снарядов)
└── audio/             # Звуковые эффекты и музыка
```

## 🚀 Запуск и тестирование

1. Откройте проект в **Godot Engine 4.7.2 Standard (64-bit)**.
2. Для запуска одиночной песочницы запустите главную сцену (`F5`).
3. Для локального мультиплеера используйте опцию Godot: `Debug -> Run Multiple Instances -> 2 Instances`.
