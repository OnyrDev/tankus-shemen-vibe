# Руководство по режиму разработчика (Debug Mode) — TANKUS

Режим разработчика (`Debug Mode`) предназначен для оперативного тестирования боевого баланса, характеристик танков, карточной прогрессии способностей, сетевой синхронизации и производительности прямо во время игры или в песочнице.

---

## 🚀 Активация и горячие клавиши

| Клавиша | Назначение |
| :--- | :--- |
| **`F3`** | Включение / выключение оверлея отладки |
| **`Tab`** / **`F4`** / **`~`** | Переключение курсора: **Захват для управления танком (`MOUSE_MODE_CAPTURED`)** ⟷ **Свободная мышь для поиска и кликов (`MOUSE_MODE_VISIBLE`)** |
| **`Escape`** | Быстрое закрытие режима отладки с возвратом управления в игру |

---

## 📊 1. Цифровые статы танка (Нижний левый угол)

В левом нижнем углу экрана расположена панель `TankStatsPanel`, выводящая **точные цифровые значения** всех производных характеристик локального танка в реальном времени (обновление 10 раз в секунду).

### Отображаемые параметры:
- **`HP`**: `Текущее / Максимальное` (учитывает стаки карт `Tankier`, `Glass Cannon`, `Tiny Tank`, `Big Tank`).
- **`Move Speed`**: Базовая скорость перемещения в м/с (база 8.00 м/с).
- **`Jump Vel`**: Вертикальная скорость прыжка в м/с (база 8.00 м/с, модификатор `High Jump`).
- **`Air Control`**: Коэффициент маневренности и управляемости в воздухе (база 0.30, модификатор `Air Control`).
- **`Damage`**: Разовый урон базового снаряда (база 28.0 ед.).
- **`Magazine`**: Ёмкость обоймы и текущий запас снарядов (база 6 шт., модификатор `Big Magazine`).
- **`Tank Scale`**: Множитель масштаба коллизии и визуальной модели корпуса (база 1.00x).
- **`Knockback`**: Коэффициент сопротивления физическому отталкиванию от снарядов и ударов (база 1.00x).
- **`Proj Speed`**: Скорость полёта снаряда в м/с (база 24.0 м/с, модификаторы `Fastball`, `Heavy Shell`).
- **`Bounces`**: Максимальное количество рикошетов от стен (база 0, активируется картой `Bouncy`).
- **`Proj Size`**: Масштаб 3D модели и хитбокса снаряда (база 1.00x, модификатор `Big Shot`).
- **`Fire Rate`**: Минимальный интервал между выстрелами и скорострельность в выстр/сек (база 0.55 с / 1.8 выстр/с).
- **`Reload Time`**: Длительность перезарядки обоймы (база 1.80 с, модификатор `Quick Reload`).
- **`Block Dur`**: Длительность активного окна щита (база 0.35 с, модификатор `Long Block`).
- **`Block CD`**: Время восстановления защитного блока (база 3.00 с, модификатор `Quick Guard`).
- **`Linear Vel`**: Фактическая текущая скорость перемещения танка в пространстве арены (м/с).

> [!NOTE]
> **Автоматическая адаптация позиции:** Если на экране активен боевой интерфейс (`HUD`), панель статов автоматически позиционируется прямо над полоской здоровья (`offset_bottom = -112.0`), не перекрывая её. В сценах без HUD панель стыкуется к самому нижнему краю (`offset_bottom = -16.0`).

## 🔍 2. Поиск и добавление карточек (Правая панель)

Правая панель `CardSearchPanel` предоставляет полноценный каталог всех 45 способностей игры с возможностью мгновенного поиска и ручного добавления/удаления.

### Возможности:
1. **Живой поиск по названию (`SearchBox`):**
   - Интерактивный `LineEdit` осуществляет мгновенную фильтрацию по подстроке в названии (`display_name`), идентификаторе (`id`) и тексте описания.
   - Во время ввода текста управление танком временно деактивируется (`tank.input.enabled = false`), предотвращая паразитные выстрелы, прыжки или движение от WASD/Space/R/E.
2. **Фильтрация по категориям:**
   - Кнопки: **`All (45)`**, **`Shot`** (18 карт), **`Block`** (9 карт), **`Jump`** (6 карт), **`General`** (12 карт).
3. **Управление стаками в билде:**
   - **`+ Add`**: добавляет 1 стак выбранной карты локальному танку. При игре по сети автоматически отправляется RPC-синхронизация (`c2s_choose_card` / `s2c_card_added`). Статы в левом нижнем углу мгновенно пересчитываются.
   - **`- Del`**: удаляет 1 стак карты с пересчётом параметров (`TankBuild.remove_card()`).
   - Индикатор **`[xN]`**: подсвечивает зеленым текущее количество карт в билде игрока.
4. **Быстрые действия:**
   - **`Clear Build`**: полный сброс всех карт танка до заводских характеристик.
   - **`+ Random`**: добавление случайной способности из базы данных.
   - **`Heal 100%`**: мгновенное восстановление полного запаса HP для тестирования урона.

## 🖱️ 3. Архитектура обработки ввода и курсора мыши

Для того чтобы разработчик мог переключаться между кликами в меню и тестированием управления без выхода из дебага, реализована бесконфликтная схема захвата мыши:

1. **Приоритет в `_input`:**
   - Обработка клавиш **`Tab`**, **`F3`**, **`F4`**, **`Escape`** вынесена в `_input(event)`.
   - Перехват срабатывает **до** GUI-системы навигации Godot и экшена таблицы очков `scoreboard`. Вызов `get_viewport().set_input_as_handled()` предотвращает побочные эффекты.
2. **Исключение перехвата фокуса кнопками (`FOCUS_NONE`):**
   - Всем кнопкам оверлея назначен `focus_mode = Control.FOCUS_NONE`. Клик по ним не захватывает фокус клавиатуры, поэтому последующее нажатие `Tab` всегда переключает режим курсора, а не пытается переключить фокус на соседний контрол.
3. **Бесшовный цикл тестирования:**
   - Открыл `F3` -> вбил в поиск "Heavy" -> нажал `+ Add` -> нажал `Tab` -> покатался и пострелял новыми мощными снарядами -> нажал `Tab` -> нажал `Clear Build`.
