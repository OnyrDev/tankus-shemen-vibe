# План реализации: TANKUS (3D Party Arena / ROUNDS with Tanks)

Реализация законченного playable MVP игры **TANKUS** на **Godot 4.7.x** с использованием **typed GDScript**. 
Игра представляет собой динамичную 3D party arena game на 2–8 игроков с раундовой системой, одной жизнью на раунд и карточной прогрессией способностей между раундами (по схеме *ROUNDS*: проигравшие драфтят улучшения, нивелируя отставание). 

Сетевой стек MVP: **ENet LAN + UDP Discovery** с фасадом `NetworkManager` для бесшовного перехода на Steam в будущем.

---

## Статус проекта и окружение

- **Рабочая папка проекта:** `D:\Projects\tankus`
